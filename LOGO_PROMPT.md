# 🎨 SafeDoc AI Logo - Gemini Image Generation Prompt

## Copy this prompt into Gemini:

```
Create a modern, professional logo for "SafeDoc AI" - an AI-powered business document platform.

Design Requirements:
- Style: Minimalist, clean, tech-forward, corporate
- Shape: Rounded square or shield icon
- Color Palette: Blue gradient (#4F46E5 to #7C3AED) with subtle purple accent
- Icon Element: Combine document/paper and shield/security symbol
- Must convey: Trust, Security, AI/Technology, Professionalism
- Format: Flat design, no gradients on icon itself (solid colors only)
- Scalability: Must work at 16x16px (favicon) and 512x512px
- Background: Transparent or white
- Typography: NOT needed in logo (just the icon)

Visual Inspiration:
- DocuSign (but more modern)
- Notion (clean, minimal)
- Linear (sharp, technical)
- Stripe (professional, trustworthy)

The logo should suggest:
✓ Document automation
✓ AI intelligence
✓ Security and compliance
✓ Business-grade quality
✓ Innovation

Please create a simple, iconic mark that represents SafeDoc AI's mission: making business documents intelligent, secure, and effortless.
```

## Once You Have the Logo:

1. **Generate in Gemini**: Use the prompt above
2. **Download**: Save as `logo.png` (512x512px or larger)
3. **Create Favicon**: Resize to 32x32px as `favicon.ico`
4. **Place Files**:
   - `web-app/public/logo.png` (main logo)
   - `web-app/public/favicon.ico` (browser icon)
5. **Update Code**: Replace 📄 emoji with actual logo

## Brand Guidelines:

### Primary Colors
- **Blue**: #4F46E5 (Indigo-600)
- **Purple**: #7C3AED (Purple-600)
- **White**: #FFFFFF

### Secondary Colors
- **Gray 900**: #111827 (Dark backgrounds)
- **Gray 600**: #4B5563 (Body text)
- **Gray 300**: #D1D5DB (Borders)

### Typography
- **Headings**: Inter, Bold, 600-700 weight
- **Body**: Inter, Regular, 400 weight
- **Monospace**: Fira Code (for code blocks)
