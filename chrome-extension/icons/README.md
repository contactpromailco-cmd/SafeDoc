# Extension Icons

These are placeholder SVG icons for the SafeDoc Chrome Extension.

For production, replace with professionally designed icons that match the SafeDoc brand:
- icon16.svg - Extension toolbar icon (16x16px)
- icon32.svg - Not required but good to have (32x32px)
- icon48.svg - Extension management page (48x48px)
- icon128.svg - Chrome Web Store listing (128x128px)

Design guidelines:
- Use the SafeDoc color palette (#EAB308 accent, #09090B background)
- Keep design simple and recognizable at small sizes
- Export as PNG for final submission to Chrome Web Store
